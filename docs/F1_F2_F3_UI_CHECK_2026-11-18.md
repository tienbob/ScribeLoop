# Native templates, Search and Ask — 18 November 2026

F3 slices 3–4 are implemented. F1/F2 remain closed under the user's existing
approval; these are additional native checks and fixes, not a new model-quality
acceptance claim. No private meetings, live capture, real provider requests or
external message sending were used during the preview checks.

## Delivered UI

- Settings → Notes: six built-ins, workspace default, static outline preview,
  custom templates, section ordering and English/Vietnamese labels, and a separate
  Personal guidance editor. Provider/model/key controls stay in Models.
- Custom creation/edit/deletion and the default are local Settings drafts until
  Save changes. Cancel/outside dismissal discards unsaved drafts. Built-ins create
  custom copies. Bounded validation runs locally and on the server.
- Templates/default commit together in SQLCipher, with a library revision check
  that rejects an outdated Settings draft. This transaction is separate from
  personal/provider settings in Keychain. Partial-save errors name acknowledged
  steps; retries do not silently acknowledge unsaved personal guidance.
- Meeting → Notes: per-meeting template choice, Preview, Generate notes/Regenerate,
  original saved-template badge, mismatch explanation and snapshotted generation
  status. Selecting a template does not regenerate old notes.
- Saved-generation definitions control section order/headings in native notes,
  Markdown and email drafts. Existing source links and validation remain in place.
  Unsupported optional sections stay hidden. Legacy notes keep their prior layout
  and an explicit General / legacy badge.
- Template changes refresh the selected meeting, so an edited/deleted template
  cannot leave its old definition in the meeting preview.

## Fixes discovered during the check

1. SwiftUI retained the Ask sheet's initial `@State` scope when the entry changed
   from all to current. The sheet now has an identity bound to its entry and,
   for current scope, meeting ID. The fixed behavior was checked in the rebuilt UI.
2. Manual Generate omitted the backend's cloud text-consent field. The explicit
   Generate/Regenerate command now supplies it; the Notes controls display the
   configured model/destination. No live cloud call was used to validate access.
3. Search now focuses its query field when opened, matching Ask's keyboard entry.

## Verification and remaining limits

- New API/storage regressions cover draft commits, stale-library rejection,
  default versus per-meeting choice, receipt replay, atomic rollback after a SQL
  failure, Unicode drafts exceeding the old command limit, and saved presentation
  after template deletion in both English and Vietnamese.
- Native client regressions cover distinct SQL-template and personal-settings
  acknowledgments, generation state, and the existing Search/Ask request binding,
  Stop/history/transcript navigation checks.
- Final complete Python suite: **1,017 passed, 2 skipped** (42.49 seconds),
  using the project test environment. The packaging environment lacks the already
  declared `defusedxml` test dependency, so it was not used for the full suite.
- Final native audit executable passed. Production app rebuilt successfully and
  bundle verification passed: 40 native binaries, zero external dependencies,
  no bundled recordings or operator transcription credential; macOS 13 minimum.
  Signing is local ad-hoc, not Developer ID/notarized release signing.
- The development build script reset ScribeLoop's ScreenCapture and Microphone
  approvals as configured; capture permissions need local approval again. The
  running production process was not restarted or used for regeneration.
- Ruff passes. The pre-existing trailing space in DesktopClient.swift was preserved
  with the user's existing local edit; no new whitespace errors were introduced.
- Automatic built-in heading locale uses Vietnamese diacritics in the saved
  overview when no explicit language policy exists; other output uses English
  labels. This is a presentation heuristic, not a model-reported language field.
- This does not establish live provider quality, a human grounding score, every
  keyboard/playback/filter combination, or the full F3 acceptance matrix. Real
  cloud generation and production-meeting regeneration were not performed.
